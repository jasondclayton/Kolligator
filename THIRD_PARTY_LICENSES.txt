Kolligator is distributed as a binary. It is built with, and includes, the

  Component        Version            License    Used for
  ---------------  -----------------  ---------  -------------------------------
  Dear ImGui       1.91.5 (docking)   MIT        user interface (compiled in)
  ProggyClean.ttf  (in Dear ImGui)    MIT        interface font (compiled in)
  GLFW             3.4                zlib       window and input (compiled in)
  CFITSIO          4.3                NASA (BSD-like)  reading FITS images
                                                 (shared library)

The AppImage also contains the shared libraries that CFITSIO depends on
(libcurl, GnuTLS, Nettle, ...), taken unmodified from the Ubuntu/Debian
packages of the build system. Their copyright and license files are in the
"bundled-libraries" folder next to this file inside the AppImage
(usr/share/doc/kolligator/bundled-libraries; run the AppImage with
--appimage-extract to see them), together with the list of the exact
package versions, whose source code is available from the Ubuntu archive
(https://packages.ubuntu.com, "apt source <package>").

The .deb package does not include them: it uses the copies installed by the
system's package manager, each with its own license file in
/usr/share/doc/<package>/copyright.
